## 🚀 **Quick Web App Setup**

### **1. Local Development**
```bash
# Install web dependencies
pip install flask flask-cors

# Run web app locally
python web_app.py

# Open browser to: http://localhost:5000
# Enhanced UI: Glass Morphism design with animations
```

### **2. Azure Deployment**
```bash
# Deploy to Azure App Service
./deploy_azure.sh

# Access: https://aquaguard-ai-webapp.azurewebsites.net
# Enhanced UI maintained in production
```
